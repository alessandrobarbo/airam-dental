# Clínica Dental Airam

Nova versão do site da Clínica Dental Airam (Boadilla del Monte, Madrid).

- Site estático em HTML/CSS/JS puro, sem dependências nem build.
- Páginas: `index.html` (principal), `aviso-legal.html`, `privacidad.html`, `cookies.html`.
- Imagens (`img/`) e fonte Maven Pro (`fonts/`) hospedadas no próprio site: nenhum pedido a terceiros ao abrir a página.
- O mapa do Google só carrega quando o visitante clica em «Cargar mapa».
- Todos os CTAs levam ao WhatsApp (`wa.me/34916334636`) ou ao telefone `+34 91 633 46 36`.

## Antes de publicar

Faltam dados da clínica para completar o aviso legal: número de colegiado de cada dentista e colégio profissional, dados completos do Registro Mercantil e confirmação do número de registro sanitário (CS-04932).

Para ver localmente, abra `index.html` no navegador.
